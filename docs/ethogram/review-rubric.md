# Behaviour scorecard review rubric

Score each criterion from 0 to 10 for each evidence set, then give a forced ranking with reasons, the three worst problems, and one additional idea.

- **Metric and citation validity:** 10 means primary publications independently checked via web search; each numeric target has paper, figure/table, statistic, units, population and assay; measurement definitions match the observable; missing biology and incompatible assays cannot earn credit.
- **Honesty:** 10 means the brain alone decides through senses; calibration has a biological or measured basis, no benchmark chasing; all stand-ins, exclusions, censoring, small sample sizes and uncertainty are explicit.
- **Overall behaviour score:** 10 means broad, reproducible, condition-matched agreement across walking, turning, spatial exploration, grooming, feeding and escape; absent evidence never counts as success.
- **Regressions and cost:** 10 means behaviour tests, CPU budgets, lint and typecheck pass; only audit code incurs new cost; required brain/native parity is retained.

Judge runnable code and recorded measurements. Verify citations against the papers via web search, rather than trusting evidence summaries. Read only the listed evidence paths and rubric. Do not inspect git history, PR discussion or review logs.
