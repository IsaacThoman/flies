## Validation

The full npm test run used two test processes at a time, paused/released at the slot boundary and resumed in a fresh window. Functional result: 733 passed, 2 skipped, 0 failed. Lint and typecheck passed. The separate CPU-budget phase failed on unchanged packages/brain/src/cost.budget.ts: everything-at-once cost 0.565 M5 Pro CPU seconds per simulated second, limit 0.5. An isolated repeat also failed, at 0.577. No brain or budget code was modified to change that result. Capture sweeps verify actual simulation fingerprints and tightly bound GPU pixel rounding; generation is repeated after capture changes.
